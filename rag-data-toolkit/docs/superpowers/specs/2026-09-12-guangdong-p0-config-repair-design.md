# 广东教育与人才 P0 三站配置修复设计

## 目标

修复 P0 任务中三个已确认的配置问题，使高校毕业生政策清单、广东教育政策法规、广东教育政策解读都能发现有效 URL、提取正文，并在不清理其他七个来源结果的前提下重新合并任务数据。

## 范围

- 更新 `config/sites/gd_seed_graduate_policy.yaml` 中已失效的详情页 URL。
- 调整 `config/sites/gd_edu_policy.yaml` 的入口和列表规则，覆盖教育政策法规的实际子栏目文章。
- 将 `config/sites/gd_edu_explain.yaml` 恢复为当前解析器支持的嵌套字段结构。
- 增加仅针对这三个 YAML 的配置回归测试。
- 对三个来源分别执行结构检查、小批量抓取、目标来源重跑和任务重新合并。

## 非目标

- 不修改公共爬虫、抽取器或清洗器 Python 实现。
- 不清理或重跑其他七个已成功来源。
- 不调整 RAGFlow、切片、向量模型或问答提示词。
- 不覆盖与本次修复无关的工作区改动。

## 实现方案

### 高校毕业生政策清单

将旧的 404 地址替换为广东省人力资源和社会保障厅当前可访问的官方政策清单详情页。保留 `start_mode: detail`，使用项目现有的详情页字段结构。

### 教育政策法规

使用广东省教育厅教育政策法规下的真实子栏目作为列表入口，并配置只匹配这些子栏目中 `/content/post_*.html` 文章链接的选择器。分页仍使用各子栏目的 `index_{page}.html` 形式；首轮验证限制为少量页面和文档。

### 教育政策解读

保留当前可用的列表入口和保守自动发现兜底，但将详情字段统一为解析器实际读取的：

- `detail.title.selectors`
- `detail.content.selectors`
- `detail.publish_time.selectors`
- `detail.source.selectors`

删除解析器不识别的 `title_selector`、`content_selector`、`date_selector` 等详情字段，避免规则抽取静默退化为通用抽取。

## 测试与验收

1. 回归测试先证明当前配置存在以下失败：旧详情 URL、错误详情字段结构、政策法规无有效文章入口。
2. 修改配置后，配置回归测试通过。
3. 三个站点的 `inspect` 均至少发现一个有效详情候选或将详情页识别为有效文章。
4. 每个站点小批量抓取后 `final.jsonl` 至少包含一条正文有效记录。
5. 使用任务的站点过滤功能只重跑三个目标来源，不使用 `--clean-run`。
6. 重新合并后 `combined_final.jsonl` 存在且包含三个目标来源的有效记录。
7. 完整测试套件通过，最终 Git diff 仅包含本次授权的配置、测试和设计/计划文档，以及运行产生的既有报告更新。

## 风险控制

- 官方栏目结构可能随时间变化，因此验收依赖实时 `inspect`，而不是只验证 YAML 语法。
- 政策法规存在多个子栏目；优先选择省级规范性文件与地方教育政策法规入口，避免把栏目导航或全站链接当作正文。
- 重跑时不得使用 `--clean-run`，防止再次清除已成功来源。
